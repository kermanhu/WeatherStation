# 自建气象站 · 项目档案

上海南向阳台外侧的微型气象站，2026-05-22 起持续运行，每 10 分钟采集一次。
截至 2026-09-26，累计约 1.3 万条观测记录。

---

## 一、硬件

| 模块 | 型号 | 测量量 | 备注 |
|---|---|---|---|
| 主控 | Arduino UNO R4 WiFi | — | 采样 + HTTP 服务 |
| 温度/气压 | BMP280 | 温度、气压 | 温度主传感器 |
| 湿度 | DHT11 | 相对湿度 | 量程 20~90%，超限输出 99% |
| 风速 | 两杯式风速计 | 风速 | 装在阳台内部，测不到室外风 |
| 风向 | 电位器风向标 | 0~360° | — |
| 雨量 | 称重式（HX711 + 94mm 口径） | 降水量 | 精度 0.1mm，易受风振噪声 |

**位置**：南向阳台外侧，传感器离墙面约 1.5m，顶部有遮阳罩。

**已知硬件缺陷**：
- 风速计在室内，`wind_max` 恒为 0.00，**不用于分析**。
- 遮阳罩只挡高角度太阳。晨昏（8:00~10:00、16:00~18:00）低角度光线会斜射进传感器区域，造成 +2℃ 左右的辐射误差。
- 称重式雨量计在静稳天气下会有零星非零读数（0.1~1mm），无连续过程，判定为风振噪声。

## 二、数据接口

### `/api`

返回当前观测的 JSON：

```json
{
  "temp": 28.7, "hum": 91, "press": 101.24,
  "wind": 0.00, "dir": 64, "rain": 0.00,
  "dew": 27.0, "appt": 36.3, "wetb": 27.4,
  "boot": "2026-09-18 11:51:12"
}
```

### `/csv`

返回完整历史 CSV，字段顺序：

```
timestamp,temp,hum,press,wind_max,dir,rain,dew,appt,wetb
```

| 字段 | 含义 | 单位 |
|---|---|---|
| timestamp | 观测时间 | `YYYY-MM-DD HH:MM:SS` |
| temp | 温度（BMP280） | ℃ |
| hum | 相对湿度（DHT11） | % |
| press | 气压 | kPa |
| wind_max | 周期内极大风速 | m/s（**不分析**） |
| dir | 风向 | ° |
| rain | 周期内增量雨量 | mm |
| dew | 露点 | ℃ |
| appt | 体感温度 | ℃ |
| wetb | 湿球温度 | ℃ |

## 三、核心发现

### 3.1 夜间偏差：+1.0℃

| 夜间 | 自建最低 | 官方最低 | 偏差 |
|---|---|---|---|
| 9/22→23 | 25.6 | 24.7 | +0.9 |
| 9/23→24 | 24.9 | 23.9 | +1.0 |
| 9/24→25 | 25.4 | 24.3 | +1.1 |
| 9/25→26 | 27.3 | ~27 | ~+0.3 |

**结论**：高露点夜间，两站都被露点托住，偏差稳定在 +1.0℃；露点极高（≥27℃）时，偏差进一步缩小。

### 3.2 白天偏差：+2℃（仅太阳直射时）

2026-09-25 实测：
- 10:00 传感器被低角度直射 → 33.9℃（官方预报 32℃，偏差 +1.9℃）
- 10:50 太阳升高，遮阳罩生效 → 31.5℃（接近官方值）

**结论**：白天偏差**取决于太阳直射角度**，不是固定值。数据修正时只应处理明显被直射的时段。

### 3.3 露点是夜间降温的物理上限

露点高则降温难。历史样本：

| 傍晚露点 | 夜间最低 | 差值 Δ |
|---|---|---|
| 20.0℃ | 24.4℃ | +4.4 |
| 24.0℃ | 25.4℃ | +1.4 |
| 24.0℃ | 25.6℃ | +1.6 |
| 27.5℃ | 27.3℃ | −0.2（封顶） |

**结论**：露点 ≥24℃ 时，夜间最低温基本被锁在露点上方 1~2℃；露点 ≤20℃ 时，Δ 才拉开到 4℃ 以上。

### 3.4 位置修正显著改善数据质量

传感器从阳台内部移到外侧后，夜间偏差从 **4~5℃** 降到 **1.0℃**。这是本项目最重要的硬件改进。

### 3.5 空调外机已排查

夏季空调外机全季运行，数据中**无可见异常**。判定为对本站无影响。

### 3.6 雨量计噪声

静稳天气下，雨量字段会出现孤立非零读数（0.1~1mm），无连续过程。判定为称重式雨量计受风振或热漂移影响，**分析时应过滤**。

## 五、待验证假设

1. **偏差随季节变化**：目前只有夏季高露点样本（+1.0℃）。秋季（10~11 月）偏差可能先扩大后缩小，需要实测。
2. **低露点端 Δ**：露点 ≤18℃ 的样本极少，Δ = 4~6℃ 是外推值。
3. **冷空气 + 大风条件下偏差**：有风时混合增强，建筑保温削弱，偏差可能缩小到 +0.5℃。
4. **建筑保温的逐夜衰减**：连续晴冷多夜后，墙体逐夜冷却，放热强度递减，偏差可能缩小。

## 六、数据修正规范

1. **温度**：只处理明显被太阳直射的时段（晨昏 + 突刺）。修正后露点、体感、湿球用公式同步重算。
2. **雨量**：孤立非零读数（无连续过程）归零。
3. **露点**：不得超过温度，超过 28.5℃ 需核对。
4. **气压**：长时间固定不变，可能是 I2C 通信失败。

**重算公式**：

```python
import math

def dewpoint(T, RH):
    a, b = 17.27, 237.7
    g = math.log(RH/100) + a*T/(b+T)
    return b*g/(a-g)

def appt(T, RH, ws=0):
    e = (RH/100) * 6.105 * math.exp(17.27*T/(237.7+T))
    return T + 0.33*e - 0.70*ws - 4.00

def wetbulb(T, RH):
    return (T*math.atan(0.151977*math.sqrt(RH+8.313659))
            + math.atan(T+RH) - math.atan(RH-1.676331)
            + 0.00391838*(RH**1.5)*math.atan(0.023101*RH)
            - 4.686035)
```
